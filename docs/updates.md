# Установка и обновления

Для установки запустите `SteamSwitcher-v0.7.4-Setup-x64.exe`. По умолчанию программа
устанавливается для текущего пользователя в `%LOCALAPPDATA%\Programs\Steam SDA`;
можно выбрать другую папку. Права администратора не требуются. Установщик добавляет
Steam SDA в меню «Пуск» и список установленных приложений Windows. Ярлык на рабочем
столе можно включить отдельно.

Следующий установщик находит прежнюю папку по записи Inno Setup с постоянным
`AppId=SteamSDA.Desktop`. Выбранный нестандартный путь также сохраняется.
Распакованные ZIP версий до 0.7.2 не регистрировались как установленная программа:
при первом запуске установщика их папку можно выбрать вручную. Поиск всего диска
не выполняется.

В приложении откройте «Обновления». Автоматическая проверка включена по умолчанию
и выполняется в фоне не чаще раза в сутки; её можно отключить в этом окне.
«Проверить сейчас» выполняет запрос сразу. Если доступен новый стабильный выпуск,
кнопка «Скачать и установить» загружает установщик, проверяет размер и SHA-256 из
GitHub Releases, закрывает Steam SDA и запускает установку. После успешной установки
приложение открывается снова. Загрузка не блокирует интерфейс и допускает отмену.
Само наличие нового выпуска не закрывает приложение и не начинает установку.

Обновлятор определяет папку по регистрации Windows. Если регистрации нет, готовая
переносимая сборка обновляется в папке своего EXE и становится зарегистрированной
установкой. Обновление из исходников через установщик отключено.

Незавершённое переключение или обновление сессии блокирует закрытие приложения.
Установщик не завершает Steam или другие процессы принудительно. Если файлы заняты,
закройте использующую их программу и повторите установку.

Аккаунты, сессии, настройки и HWID остаются в `%APPDATA%\SteamSDA`. Обновление и
обычное удаление программы через Windows это хранилище не удаляют. Удаление аккаунта
из базы выполняется отдельной кнопкой в приложении.

Проверка обращается только к публичному API репозитория
`fabbiodev/steam-switcher`. Логины, токены Steam и HWID в запросы не включаются.
Установщики хранятся в `%LOCALAPPDATA%\SteamSDA\updates`; неполная загрузка удаляется.
Повреждённый файл, неизвестный адрес, предварительный выпуск и понижение версии
не допускаются к установке. Перед запуском установщика SHA-256 проверяется повторно.

В GitHub Actions установщик проверяется отдельно: установка в нестандартную папку,
повторная установка без `/DIR`, замена файлов, обнаружение пути приложением, запуск
установленного EXE и удаление с сохранением контрольного файла в каталоге данных.
